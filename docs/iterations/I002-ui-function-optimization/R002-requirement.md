# I002-R002 自举诊断故障模拟与侧栏折叠方案

**需求状态：** 待验收
**验收报告：** [R002-requirement-acceptance.md](R002-requirement-acceptance.md)

## 背景与目标

为自举诊断提供可重复的 API 错误及关联日志；解决侧栏折叠按钮遮挡用户名的问题。用户已指定采用侧栏边界处的尖括号控制样式，十种预览不再作为待选方案。

## 范围与任务

| 任务 | 产出及验收标准 | 依赖 | 状态 |
| --- | --- | --- | --- |
| T01 故障 API | 登录后请求 `GET api/v1/mock/errors` 随机返回错误；`number=1001..1010` 精确指定；校验非法编号；复用统一错误结构、日志、请求 ID、限流 | 现有身份及 HTTP 中间件 | 待验收 |
| T02 页面触发 | 点击 WORKSPACE 只发送一次模拟请求，标题栏中央展示 HTTP 状态、错误编号及消息；模拟 401 不刷新会话；资源子页面也在主标题栏展示 | T01 | 待验收 |
| T03 侧栏折叠 | 在正式侧栏边界使用向左/向右尖括号表示折叠/展开；竖线分别连接到当前尖括号的上下端点；保留键盘交互、偏好持久化，按钮不得遮挡用户名 | 现有视觉基准 | 待验收 |

## 边界、风险与回滚

- 不实际破坏数据库、资源或进程，不新增配置项，不改变认证或权限模型。
- 模拟故障用 `error.code` 表达统一消息码（`M0001`–`M0010`）；请求参数 `number=1001..1010` 用于指定场景，不在响应中重复返回。日志仍以 `mock=true` 和 `error_number` 标记，避免与真实故障混淆。
- 模拟请求会产生真实 HTTP 错误、错误日志及监控信号；4xx 沿用 WARN，5xx 沿用 ERROR。
- 静态预览仅作为历史候选，不把预览打入生产构建。
- 回滚为移除新增路由、前端入口与预览，不涉及数据迁移。

## 统一验收

后端覆盖全部编号、随机结果、参数错误、身份限制、日志关联；前端覆盖模拟 401 不重试与标题栏提示；侧栏检查尖括号方向、折叠交互、用户名与按钮不重叠。执行相关测试、静态检查、前端构建与差异检查，证据记录到验收报告。
