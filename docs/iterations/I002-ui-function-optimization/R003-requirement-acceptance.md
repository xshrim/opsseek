# I002-R003 验收：公共消息码与消息组件优化

**验收结论：** 实施中。

## 执行记录

后端统一错误响应新增 `error.type`，保留调用方传入的稳定类别短码；`error.code` 继续提供固定五位展示码。前端 `ApiError` 保留 `type`，公共消息组件以中性色标签显示，WORKSPACE 故障横幅同时展示 HTTP 状态、展示码、类型短码和正文。

导航栏的 WORKSPACE 标签行框底边对齐右侧标题栏分隔线，文字水平居中；折叠时隐藏标签但保留布局高度，使菜单图标垂直位置不变。折叠图标使用与侧栏分隔线相同的颜色和 1px 描边。

验证通过：`go test ./httpapi`（含完整展示码映射与类型回归测试）、`npm run check`、`npm run test`（13 个文件、70 项）、`npm run build`，以及 Playwright 折叠图标/菜单纵向位置与模拟故障两项用例。

全量公共消息审计仍未完成，因此本需求的最终验收结论保持实施中；目前未验证所有非 API 表单行内提示是否都有专属消息码。
