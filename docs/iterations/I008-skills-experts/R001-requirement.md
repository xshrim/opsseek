旧技能以执行计划、强制 Schema 和短指令为中心，不能完整保留标准技能目录；先建立无执行副作用的包模型，再接入持久化、API 和界面。

## 2. 目标与范围

权威模型与边界见 [设计文档](../../design/skills-and-experts.md)，本文件仅记录交付任务。

## 3. 非目标

远端自动下载、任意脚本执行、依赖安装、旧专有格式兼容。

## 5. 任务说明

### T01 标准包解析与安全边界

**实施范围：** 在 backend/skill 建立标准 SKILL.md 与归档解析器，保留未知元数据和原始文件；支持多技能发现，按设计拒绝路径穿越、链接、重复路径和资源耗尽。

**验收标准：** 表驱动测试覆盖单文件、多目录、ZIP、tar.gz、.skill、空正文、非 SemVer 元数据、未知工具、缺失引用、恶意路径、超限和截断归档；导入不执行代码。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。

### T02 目录、文件和不可变版本持久化

**实施范围：** 重构技能版本与文件存储，复用 PostgreSQL；发布、默认版本、来源、内置只读、复制/删除及引用约束统一由服务端处理。

**验收标准：** 干净数据库测试验证文件字节往返、事务失败回滚、版本不可变、重复导入冲突和内置修改拒绝；不得破坏历史执行版本。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。

### T03 导入和管理 API

**实施范围：** 实现预览/确认、Scope 和权限、冲突选择、文件读取、导出及限制；确认时重新校验，不信任客户端预览结果。

**验收标准：** API 测试覆盖 400/403/404/413、伪造预览、越权对象、未授权文件、部分包失败及无副作用预览。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。

### T04 技能管理界面

**实施范围：** 复用公共表格和向导，提供上传、候选选择、能力报告、文件树/正文、版本和复制；去掉旧固定五项工具选择器。

**验收标准：** 前端检查与组件测试覆盖内置只读、导入错误定位、多技能选择、Scope、长文本、上传忙碌/取消；交互验收记录不得以静态构建替代。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。
