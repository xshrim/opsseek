# I008-R002 详细内置技能与提示词解耦

**迭代：** [I008](iteration.md)
**需求状态：** 待规划

## 1. 需求背景

当前资源技能过短，领域规则散落在诊断拼接代码和种子中。以标准包为唯一知识源，保留平台通用安全与回答规则。

## 2. 目标与范围

27 种资源各一份详细技能，加一份跨资源应用诊断技能；真实工具契约参考、幂等内置安装和提示词归属整理。

权威模型与边界见 [设计文档](../../design/skills-and-experts.md)，本文件仅记录交付任务。

## 3. 非目标

为缺乏工具的资源虚构能力或新增未批准工具；将协议 Schema 和通用规则包装成可选技能。

## 5. 任务说明

### T01 资源工具与提示词清单

**实施范围：** 核对 Catalog、Direct/Agent 适配器、输出结构和现有说明；建立类型到技能/工具的对应关系，标注缺口与动态 MCP 工具。

**验收标准：** 27 类型全部覆盖；实际工具名、参数、输出契约能定位源代码；无工具类型明确不可用而不是填通用口号。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。

### T02 标准内置包与模板

**实施范围：** 编写资源专用 SKILL.md 和 references，包含调查步骤、参数结果、限制与示例；应用技能负责运行时和跨资源关系；仓库技能合并既有仓库说明。

**验收标准：** 解析器逐包验证；工具名/Schema 漂移测试；示例可由实际定义校验；扫描无凭据、无擅自写操作、无重复大段通用规则。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。

### T03 单一来源安装与只读呈现

**实施范围：** 程序嵌入技能目录，幂等发布平台内置版本并复用管理页；删除 SQL/Go 中重复种子正文，运行入口切换由 R004 完成。

**验收标准：** 重复启动不增版本、变更内容形成新版本、历史版本保留；接口及 UI 均不可修改内置对象，可复制为自有对象。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。
