# I008-R004 运行集成与默认项目专家

**迭代：** [I008](iteration.md)
**需求状态：** 待规划
**验收报告：** [R004 验收](R004-requirement-acceptance.md)

## 1. 需求背景

导入与管理不等于执行可用。必须让运行链实际加载技能、遵循专家边界并保留现有诊断与巡检的可靠性。

## 2. 目标与范围

渐进技能加载、工具映射与授权、版本快照、项目拓扑读取及默认专家、专家组子智能体、诊断/巡检选择、全链路回归。

权威模型与边界见 [设计文档](../../design/skills-and-experts.md)，本文件仅记录交付任务。

## 3. 非目标

框架替换、全量技能全文注入、自动资源写操作、无人授权的生产回归和数据库清理。

## 5. 任务说明

### T01 渐进加载与受控工具

**实施范围：** 目录元数据进入上下文，受控激活/读取技能文件；权限、路径、限额、工具需求映射、审计及恢复使用冻结版本；移除旧硬编码领域说明。

**验收标准：** 未选技能不注入全文，激活后读取相关文件；空声明不误禁工具，未知声明不授予 Shell；版本恢复、跨 Scope 文件拒绝、内容截断及取消测试。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。

### T02 项目拓扑与默认诊断专家

**实施范围：** 提供结构化可见项目关系上下文，内置只读项目诊断专家；按显式专家/组或项目/应用目标路由，通用清单与独立资源问题不盲目分析全项目。

**验收标准：** 项目名/团队名不串用；应用关联业务库、日志与仓库版本保留；实体与实时证据区分；可见性、分页、空拓扑、默认路由及显式覆盖测试。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。

### T03 专家组与诊断巡检接入

**实施范围：** 按需分派组成员，继承范围、共享预算/取消、流式过程和证据聚合；诊断及巡检支持专家或组互斥选择、快照与恢复。

**验收标准：** 单成员失败/部分结果、取消、预算耗尽、模型重试和已输出内容保留；组成员不全量强制执行；巡检身份与已撤销权限测试。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。

### T04 端到端回归与文档收敛

**实施范围：** 清理旧路径、同步领域/API/指南，检查 main 现有功能、干净 SQL、Makefile/Docker/Compose、RBAC 与公共组件；更新验收证据。

**验收标准：** Go 定向与全量可行测试、前端 check/test/build、隔离 DB 集成、导入→选择→工具→证据链回归；未完成外部验证明确记录，用户确认后封板。

**风险和回滚：** 在实施分支按任务检查提交；涉及模型改变时使用隔离数据库验证，回滚代码不承诺兼容新结构。不得为通过测试绕过权限或修改历史验收证据。
